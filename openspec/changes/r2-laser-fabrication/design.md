## Context

见 `proposal.md - Why`。R0/R1/R1.5 已交付设计、仿真、实测链路。R2 只补「设计 → 上机产物」这一段。
已确认的环境事实（实测）：

- `kicad-cli pcb export gerbers|drill` 可从 38 个真实 demo PCB 导出**真实** Gerber 与 Excellon。
  实测 `ecc83-pp`：`%FSLAX46Y46*%`、`%MOMM*%`、孔径 `C/R/O`、33 flash、1922 draw、
  板框 4 段（`TF.FileFunction,Profile,NP`）、钻孔 33 孔（`M48`…`T1C0.800`…`X126.365Y-125.095`）。
- **没有激光雕刻机/GRBL 控制器**（无串口设备）。

约束：不引入几何库；产物必须能直接交给 GRBL；不得声称已实际打样。

## Goals / Non-Goals

**Goals:**

- 真实 Gerber + Excellon → 隔离雕刻/钻孔/板框三类走刀 → 可直接上机的 GRBL G-code + SVG 预览。
- 几何正确性**可验证**：隔离路径到铜的最小距离 ≥ 请求的安全间距；钻孔路径与 Excellon 孔位一致。
- 不支持的 Gerber 构造显式报告，绝不静默丢图形。
- 参数推荐是**起点**而非结论，责任边界写在产物里。

**Non-Goals:**

- 不做步进重复（`SR`）、镜像/旋转/缩放（`LM/LR/LS`）、负极性图形（`LPC`）的完整支持；
  遇到即报告计数。宏孔径只支持能实例化的基本图元（1/4/20/21/22），其余计数。
- 不做双面翻面对位、阻焊/丝印激光工艺、机械钻孔/铣削、非 GRBL 控制器、真实打样。

## Decisions

### D1 · 自研 RS-274X 子集解析，未支持构造显式计数

支持：`FS`（LA + 前后零省略）、`MO`（MM；IN 换算）、`AD`（`C`/`R`/`O` + 宏孔径）、`LP`（`D` 识别，`C` 报告）、
`G01`、`G02/G03`（线性化，弦高 ≤ 0.01mm，含模态插值与 `G75`）、`D01/D02/D03`、`G36/G37` 区域、
`TF.FileFunction` 层识别、`TO./TA./TD` 属性记录、`M02`。
未支持：`SR`、`LM/LR/LS`、无法构造的宏图元、负极性图形 → 计入 `unsupported` 列表并在报告中呈现。
- 实测发现（真实 KiCad 输出）：宏体内部的语句（`$2 $3 … X,Y pos of 4 corners`）看起来像数据块，
  必须按「宏定义块」整体跳过；`%TO.C,D15*%` 是元件位号属性，不能被当成选刀；圆弧模式是模态的。
- 宏孔径按定义实例化（KiCad 的 `RoundRect` 圆角矩形焊盘 = 内缩矩形 + 四角圆 + 四边带），
  而不是跳过：跳过焊盘会导致隔离走刀穿过焊盘。
- 备选：用 `gerbv`/`gerber` crate。否决：引入外部依赖、且这些构造本就需要我们自己决定语义。

### D2 · 几何用「栅格 + 轮廓跟踪」而不是精确多边形偏移

流程：铜图元 → 占用栅格（分辨率默认 0.05 mm）→ 以 `tool_radius + clearance + 半像素` 膨胀 →
边界跟踪取闭合轮廓 → Douglas-Peucker 简化（容差默认 0.02 mm，向**安全侧**取整）→ 最近邻串联。
- 理由：对 flash/draw/区域三类图元统一处理，不需要多边形布尔运算（自研 union 极易出错）。
- 代价：分辨率误差。缓解：膨胀半径额外加半个像素（安全侧），并在验收里直接校验
  「路径到铜的最小距离 ≥ 请求间距」。
- 备选：多边形偏移 + union（clipper 式）。否决：工作量大、易出几何 bug，收益在本阶段不明显。

### D3 · 坐标系归一

Gerber 用绝对坐标且 Y 可能为负（KiCad 导出）。作业坐标统一为：`x' = x - min_x`，`y' = y - min_y`
（保持 Gerber 的 Y 向上约定），并在作业里记录平移量。G-code 用 `G21`（mm）与 `G90`（绝对）。
- 理由：GRBL 与激光机通常以工件左下角为原点；负坐标虽合法但易误操作。

### D4 · GRBL 只用稳定子集

前言：`G21`、`G90`、`G94`、`G0` 回安全位、可选 `M3/M4` 与 `S`。
每层：`G0` 空程（激光关）→ `M3 S<power>` → `G1 F<feed>` 逐段 → `M5`。
收尾：`M5`、`G0 X0 Y0`、`M2`。不使用圆弧/刀具补偿/主轴指令；注释里标注板材、功率、速度、
遍数与来源（知识库或用户覆盖）。
- 理由：GRBL 方言差异主要在 M3/M4（激光模式）与 S 范围；只依赖最小公共子集最稳。

### D5 · 钻孔默认「标记」，圆形切割可选

激光很难在 FR4 上真正钻穿。默认 `Mark`：在每个孔位短暂停留（低功率定点），供后续手钻定位；
`Circle` 模式按孔径切圆（多遍）。两者都在 G-code 注释与作业统计里标明。

### D6 · 参数知识库带来源与免责

`LaserProfile { material, thickness, power_s, speed_mm_min, passes, applicability, source }`。
收录少量常见板材（单/双面 FR4 覆铜板、纸基板），**每条都标注 source 与适用范围**，
输出统一附带「这是起点，必须先试刻校准」「与具体机器相关」两句话。
- 未收录板材：返回 nearest 若干条作参考 + 明确「未收录，勿直接采用」。

### D7 · 依赖方向

`gcode-laser` 只依赖 `gcode-kicad`（复用 IR/目录做电路标识与文档链接），不依赖 sim/instrument。
工具层 `gcode-tools` 汇总所有 crate；agent 只读工具输出。

## Risks / Trade-offs

- [无硬件 → 不能证明真能打样] → 只声明「已生成产物 + 几何校验通过」；报告显式标注未上机；
  给出试刻与对刀建议。
- [栅格分辨率导致间距不足] → 膨胀半径加半像素（安全侧）+ 验收直接量测最小距离。
- [简化可能把路径推向铜侧] → 简化容差只允许向安全侧（外扩）取整，且有测试。
- [Gerber 子集覆盖不足导致图形缺失] → 未支持构造计数并报告；对 38 个 demo 板实测覆盖率并记录。
- [G-code 无法上机验证] → 只用稳定子集 + 结构校验（指令白名单、坐标有限、范围在板内）。
- [参数推荐被当作保证] → 强制免责声明进输出与 G-code 注释。
